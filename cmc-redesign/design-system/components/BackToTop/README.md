# BackToTop

A floating circular button (`navy-700`, 44px, `shadow-md`) fixed to the bottom-right corner that scrolls the page back to the top. It stays hidden until the visitor has scrolled past about a screen (`after`, default 400px), then fades in; it is keyboard-reachable only while shown.

- Place one on every page, just above the Footer.
- Keep it clear of other fixed elements: the listings compare bar sits bottom-centre and leaves the right 72px free on phones.
- Hidden when printing. Respects the phone's safe-area inset.

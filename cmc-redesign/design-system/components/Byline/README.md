# Byline

A one-line provenance strip for guides and calculator pages: who wrote it, who reviewed it, when the sources were last checked and when the page last changed, with an optional note. It sits at the end of a page's "Sources" block, inside the same card, in `surface-100` with a `teal-600` shield icon.

- Every guide and calculator carries one; dates are written in full ("14 October 2026") and updated whenever a figure or source changes.
- `author` and `reviewer` are the site's two founders; `checked` is the date the linked sources were re-read, `updated` the date the page changed.
- `note` is the page's disclaimer ("Estimates only — not financial advice") — keep it to one sentence.
- Never fabricate a check date: if a source has not been re-read, leave `checked` as it was.
